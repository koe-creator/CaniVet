# ACTA DE PROYECTO

## Nombre del proyecto
CaniVet

## Descripcion del proyecto
CaniVet es un sistema de gestion veterinaria desarrollado para facilitar el control de clientes, mascotas, citas, servicios, pagos, inventario y reportes desde una plataforma web. El proyecto busca mejorar la organizacion operativa de una clinica veterinaria mediante una solucion digital moderna.

## Objetivo general
Desarrollar un sistema web de gestion veterinaria que permita administrar de forma eficiente la informacion operativa y administrativa de una clinica.

## Objetivos especificos
- Implementar autenticacion de usuarios.
- Diseñar una base de datos adecuada para la gestion veterinaria.
- Desarrollar CRUD para clientes, mascotas, citas, servicios, pagos e inventario.
- Generar reportes utiles para la toma de decisiones.
- Integrar frontend, backend y base de datos en una sola solucion funcional.
- Documentar el proyecto tecnica y funcionalmente.

## Alcance
El proyecto incluye:
- modulo de autenticacion
- panel administrativo
- gestion de clientes
- gestion de mascotas
- agenda de citas
- control de servicios
- registro de pagos
- control de inventario
- reportes
- configuraciones del sistema

No incluye en esta version:
- aplicacion movil nativa
- facturacion fiscal avanzada
- pasarela de pago en linea
